# emina-weiv (AnimeView)

แอปพลิเคชันดูอนิเมะส่วนตัว รองรับการสตรีมมิ่ง, ดาวน์โหลดเก็บไว้ดูออฟไลน์, ซิงค์ข้อมูลข้ามอุปกรณ์ และระบบอัปเดตเวอร์ชันอัตโนมัติผ่าน GitHub Releases

## ฟีเจอร์หลัก
- **Streaming & Offline Download**: ดูออนไลน์และดาวน์โหลดตอนไว้ดูออฟไลน์
- **Picture-in-Picture (PiP)**: ดูวิดีโอต่อเนื่องขณะสลับแอป
- **Smart Next Episode**: ปุ่มข้ามไปยังตอนถัดไปอัตโนมัติ
- **Local Proxy & Stream Extractor**: ดึงและเล่นสตรีมมิ่งได้อย่างลื่นไหล
- **In-App Auto Update**: ตรวจสอบเวอร์ชันใหม่จาก GitHub Releases ดาวน์โหลดและเปิดตัวติดตั้งได้ทันทีภายในแอป

## การติดตั้ง
ดาวน์โหลด APK เวอร์ชันล่าสุดได้จาก [Releases](https://github.com/jirayusgoodlife/emina-weiv/releases)
